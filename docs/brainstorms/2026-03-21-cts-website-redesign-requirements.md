# CTS Thailand Website Redesign

## Problem Frame
The current ctsthailand.org website (Chiang Mai Theological Seminary) has an outdated WordPress design with visual clutter, broken embeds, inconsistent hierarchy, and a dense multi-language footer. The content and structure are sound but the visual presentation needs modernization to reflect the seminary's professionalism and credibility.

## Requirements

- R1. Redesign all major pages with a bold & professional visual style — strong typography, high contrast, authoritative feel
- R2. Keep all existing content sections and navigation structure intact (same pages, same information hierarchy)
- R3. Reuse existing photography and images from the current site (hero slider photos, course banners, faculty photos, library image, LINE QR, logo)
- R4. Fix visual issues: broken YouTube shortcode display, promotional banners that look like ads, cluttered layout
- R5. Create a cohesive design system (typography, colors, spacing, components) that works across all pages
- R6. Design must support Thai as the primary language with English and Chinese sections in the footer
- R7. Simplify visual noise while preserving all content — better whitespace, clearer sections, stronger visual hierarchy

## Pages to Design

1. **Homepage** — Hero slider, YouTube embed area, news article, enrollment CTA, online course promotions, quote from Dr. Henry, library/LINE links, footer
2. **About Us** — Landing page with links to subpages
3. **History** (ประวัติ)
4. **Mission / Vision / Purpose** (พันธกิจ นิมิต วัตถุประสงค์)
5. **Statement of Faith** (หลักข้อเชื่อค่านิยม)
6. **Director's Message** (สารจากผู้อำนวยการ)
7. **Faculty** — Residential and Visiting faculty pages
8. **Curriculum** — Overview page with links to each program
9. **Individual Program Pages** (Church Leaders, Diploma, MCS, MMS, M.Div Missions, M.Div Pastoral, D.Min)
10. **Enrollment** (สมัครเรียน)
11. **Online Courses** (วิชาออนไลน์แบบคลิป)
12. **Bible Series** — Landing + individual series pages
13. **Video Clips** — Chapel sermons, testimonies, podcasts, etc.
14. **News & Activities** — Newsletter, construction photos, alumni, gallery, reviews
15. **Support/Donate** (สนับสนุนพันธกิจ)

## Success Criteria
- Every page looks visually cohesive with the same design system
- The design feels bold, professional, and credible — comparable to a respected university website
- All existing content from the current site is represented
- Existing images are integrated naturally into the new design
- Thai text is readable and well-typeset throughout

## Scope Boundaries
- NOT changing the site's content or copy — only visual presentation
- NOT adding new features or functionality (e.g., no new forms, no e-commerce)
- NOT designing a mobile-responsive version separately (desktop design in Pencil)
- NOT implementing code — this is a Pencil design deliverable only

## Key Decisions
- **Style direction**: Bold & professional — strong typography, high contrast, authoritative (like a top university)
- **Content preservation**: All existing content stays; no content strategy changes
- **Tool**: Pencil MCP for all design work
- **Images**: Reuse from existing site, no new photography

## Dependencies / Assumptions
- Existing images can be sourced from the current website
- The CTS logo (cross with flame) will be retained as-is
- The yellow/gold accent color from the current site may be refined but the overall identity should remain recognizable
